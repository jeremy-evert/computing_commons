# Computing Commons visual system

Canvas-safe visual grammar: system sans-serif, ink `#172033` on paper `#f7f9fc`,
blue `#135c9e`, teal `#087f75`, amber `#9a5b00`, and text labels paired with
every color state. Use one `h1`, ordered `h2`s, shallow cards, one first
action, evidence/success and recovery callouts, and repeated Home / Back / Next
navigation. The compact shared route highlights Kickoff and Week 2 and labels
the Recitation Toolbox “as needed”, not as a rigid week.

Pages use plain HTML and inline styles only: no JavaScript, web fonts, or
required external CSS. Flexible grids and wrapping navigation degrade to a
single narrow column. Future pages should copy `templates/commons-page.html`
and preserve this small grammar rather than inventing page-specific decoration.
