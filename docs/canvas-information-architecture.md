# Computing Commons Canvas information architecture

Status: **REPOSITORY DESIGN SOURCE / NOT YET DEPLOYED**

Future Canvas target: `https://swosu.instructure.com/courses/24298`

## Design principle

Canvas should make the Commons feel like a shared workshop, not an extra full academic course.

Students should see a small number of stable doors. The repository may have many supporting documents and source registries behind those doors.

## Assignment posture

During Fall 2026 soft launch, Commons activities can be:

- due;
- 0 points;
- completion/evidence tracked;
- eligible to support home-course bonus credit.

Avoid creating duplicate grade weight in the Commons and every home course.

## Progressive visibility

When Level N is assigned, Levels 1 through N should remain accessible.

Do not design progression by hiding completed foundations. The Commons should be a place students can return to when they forget something.

## Deployment rule

Do not implement this Canvas structure until repository acceptance produces the verdict:

`READY FOR COMPUTING COMMONS CANVAS DEPLOYMENT`

Once authorized, deploy the intended structure coherently, verify it from the student-facing Canvas surface, then dogfood it before videos are recorded.
