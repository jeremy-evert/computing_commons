# Shared Finale: Farkle + Machine Learning

The Commons should preserve a common late-semester experience built around Farkle, simulation, probability, data, models, evidence, and machine behavior.

The goal is one shared phenomenon viewed through multiple disciplines, not six duplicated assignments.

## Disciplinary lenses

### Computer Science I

- implement or understand a bounded simulation;
- connect code to observable outcomes;
- explain what was tested and what the output means.

### Computer Science II

- improve design/structure;
- compare implementations;
- test behavior and reason about maintainability.

### Discrete Structures & Critical Thinking

- probability;
- counting/uncertainty;
- assumptions;
- evidence and reasoning about strategy.

### Computer Architecture

Computer Architecture has the strongest technical fit for the machine-facing portion:

- profiling;
- CPU/GPU behavior;
- throughput;
- scaling;
- memory/performance effects;
- what the hardware actually does while simulation or inference runs;
- whether “faster” and “better” are being confused.

### Software Engineering

- reproducibility;
- system structure;
- testing;
- collaboration/review;
- evidence that another person can run and understand the work.

### Machine Learning

- model framing;
- data/features;
- training;
- evaluation;
- baselines;
- uncertainty and limitations;
- whether a learned model actually improves on simpler strategies.

## Commons role

The Commons owns the shared event/phenomenon, common entry point, and any genuinely common data/starter/evidence structure.

The course repositories own the disciplinary lens and any course-specific graded application.

## Design principle

The finale should reconnect the skills students accumulated earlier in the Commons:

- local tools;
- containers/repeatability;
- documentation;
- Work First;
- Linux/profiling;
- Git;
- AI Fluency verification;
- Professional Minds judgment.

The experience should feel like the disciplines meeting in the same room, not like students receiving six independent homework packets about dice.
