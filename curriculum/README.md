# Computing Commons curriculum clearinghouse

This directory describes the student-facing composition of shared computing material. It should generally **reference canonical sources rather than duplicate them**.

## Proposed Canvas shape

1. **START HERE — Computing Commons / Recitation**
2. **Success Foundations / Semester Kickoff**
3. **AI Fluency — progressive levels**
4. **Professional Minds — progressive levels**
5. **Build and Verify Your Local AI Lab**
6. **Recitation Toolbox**
   - Containers
   - Documentation / LaTeX
   - Work First
   - Linux inspection / profiling
   - Git / source management
7. **Shared Farkle + Machine Learning Finale**

After the initial runway, the toolbox should behave like reusable workshop stations rather than a rigid weekly sequence.

## Composition principle

Each module should identify:

- canonical source repository;
- student entry point;
- required evidence/completion signal;
- progressive level, if applicable;
- home-course wrapper/application expectations;
- Canvas delivery status;
- validation status.

The Commons should not become a second authoring home when a strong canonical source exists elsewhere.
