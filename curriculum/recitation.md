# Computing Recitation

## Purpose

Computing Recitation is the shared workshop/help layer for capabilities used across multiple SWOSU computing courses.

Students should not have to decide which course “owns” a Git problem, a Local AI problem, a Linux problem, or a documentation problem before asking for help.

Bring the work. Bring the evidence. We will figure out the seam.

## Good Recitation questions

Useful starting questions include:

- What did you expect to happen?
- What command or step did you try?
- What actually happened?
- What evidence do you have?
- What is the smallest next check that would reduce uncertainty?

Students are not expected to arrive with a polished diagnosis.

## Shared topics

Recitation may support:

- Success Foundations / navigating the computing curriculum
- Local AI Lab
- Ollama / local models / Aider
- AI Fluency
- Professional Minds
- Containers
- LaTeX / Markdown / documentation
- Work First
- Linux command line
- profiling / observing the machine
- Git / source-code management
- Farkle + Machine Learning shared work

Course-specific subject tutoring can still happen, but the Commons should not absorb the disciplinary curriculum from the home courses.

## Evidence habit

A useful Recitation receipt is small:

1. **Goal** — what were you trying to accomplish?
2. **Attempt** — what did you run/do?
3. **Observation** — what happened?
4. **Next conclusion** — what does that evidence establish, and what does it not establish?
5. **Recovery** — what did you try next?

This is intentionally compatible with AI-assisted work. AI can propose a next step, but evidence decides whether the step worked.

## Schedule posture

Recitation hours may be carved out of the instructor's shared office-hours capacity rather than creating a separate meeting requirement.

The exact weekly times should come from the canonical shared office-hours source and Canvas deployment, not be hard-coded here unless explicitly adopted.

## Fall 2026

Fall 2026 is a soft launch. Recitation should make students' lives easier rather than create another attendance obligation.

Use it as:

- a recovery room;
- a workshop;
- a place to dogfood shared instructions;
- a place to discover where Commons directions are unclear;
- a feedback channel for improving the shared curriculum.
