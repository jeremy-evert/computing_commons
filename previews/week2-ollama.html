LOCAL AI LAB · STEP 4

Get or confirm Ollama

Ollama is the local service that Aider will contact; it is not the model and not Aider.

Do this first

Use the canonical classroom check for the Ollama command and loopback API at http://127.0.0.1:11434. Do not use a cloud endpoint, API key, or alternate installer story.

Evidence of success

A responding loopback API proves reachability at that moment. It does not prove that qwen3:8b is installed or can complete inference.

If this fails

Stop once, preserve W2-API-001 or the observed code, and go to Recovery. Do not scan ports or repeatedly restart services.
