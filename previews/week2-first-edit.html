LOCAL AI LAB · STEP 9

Say hello with Aider

Make one bounded request, then inspect what actually changed.

Do this first

Ask Aider for one supplied exercise change. Exit, inspect git diff, then run the independent test. Accept only the expected narrow file change.

Evidence of success

Aider generated a change; Git shows its scope; the test checks behavior. These are separate claims. A passing test still does not prove every property.

If this fails

Wrong file, extra edits, or a failing test means do not accept. Preserve the diff and use Recovery or the disposable reset.
