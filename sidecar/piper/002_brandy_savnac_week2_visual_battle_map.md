Use the existing 001A mission. Inspect current Commons truth and efficiently search current/history sources for the lost good landing-page/week-strip pattern. Recover ideas, not stale curriculum.

### Round B — Build visual grammar + Kickoff

Execute `002F_deploy_week2_visual_slice_to_savnac.md`.

## Philosophy

Savnac is the wind tunnel, not the airplane passengers board.

Build truth in Git. Render it in Savnac. Let humans and synthetic reviewers find the ugly seams while the blast radius is cheap.
